## 🚀 3 Ways to Create a Form

### **Option 1: Use a Template** (Fastest - 2 minutes)

1. Click **"Create New Form"**
2. Click **"Choose Template"**
3. Pick one:
   - 🚚 Full Moving Form (9 questions)
   - 📦 Quick Moving Form (5 questions)
   - ⭐ Customer Feedback (5 questions)
   - 📬 Contact Us (4 questions)
   - 📝 Blank (start fresh)
4. Edit the form name
5. Preview
6. Save
7. ✅ **Done in 2 minutes!**

---

### **Option 2: Use Question Library** (Fast - 5 minutes)

1. Click **"Create New Form"**
2. Enter form name → Next
3. Click **"Question Library"** button
4. Browse tabs:
   - **Contact Info** → Click "Email Address" → Added!
   - **Contact Info** → Click "Phone Number" → Added!
   - **Address** → Click "Street Address" → Added!
   - **Address** → Click "City" → Added!
   - **Address** → Click "ZIP Code" → Added!
5. Close library
6. Preview
7. Save
8. ✅ **Done in 5 minutes!**

---

### **Option 3: Build Custom** (Full Control - 10 minutes)

1. Click **"Create New Form"**
2. Enter form name → Next
3. Click **"Add Question"**
4. See **Quick Add** buttons:
   - Click **"👤 Full Name"** → Question pre-filled!
5. Or type custom:
   - "What items are you moving?"
6. See **live preview** as you type
7. Choose answer type (click the card with icon)
8. Check ☑ Required if needed
9. Click **"Add Question"**
10. Repeat for more questions
11. **Drag** questions to reorder
12. **Duplicate** similar questions (⎘ icon)
13. **Group** into sections
14. Add **conditionals** (show/hide)
15. Preview **desktop & mobile**
16. Save
17. ✅ **Done in 10 minutes!**

### **For Speed:**

1. ✅ Start with a template
2. ✅ Use Question Library for common fields
3. ✅ Duplicate similar questions
4. ✅ Use Quick Add buttons in dialog

### **For Quality:**

1. ✅ Always preview on mobile
2. ✅ Group related questions in sections
3. ✅ Mark important questions as required
4. ✅ Use conditionals to reduce clutter

### **For Safety:**

1. ✅ Undo is your friend
2. ✅ Preview before saving
3. ✅ Test the form yourself first
4. ✅ Start with fewer questions, add later

## ❓ **Common Questions**

**Q: Can I use a template and customize it?**  
A: Yes! Templates are just a starting point. Edit anything!

**Q: What if I delete a question by mistake?**  
A: Click the Undo button (↶). Goes back 5 steps!

**Q: How do I reorder questions?**  
A: Three ways:

1. Click and drag the [☰] icon
2. Use up/down arrows
3. Duplicate and delete original

**Q: Can I add the same question to multiple forms?**  
A: Yes! Use Question Library. Same question, always consistent.

**Q: What's the difference between templates?**  
A: Length and purpose:

- Quick = 5 questions (fast to fill)
- Full = 9 questions (comprehensive)
- Feedback = for reviews
- Contact = for inquiries

**Q: Do I need to understand "conditionals"?**  
A: No! It's optional. Basic forms don't need it.

**Q: How do I know if my form looks good on phones?**  
A: Click the 📱 Mobile button in preview. You'll see exactly how it looks!
